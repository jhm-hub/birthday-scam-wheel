# Saved versions, one OBS source

Settings are saved in this browser on this computer. Use the same browser/profile each time; this is not an account or cloud backup.

- **Save changes** updates the selected version.
- **Save as new version** keeps another setup, without creating another OBS source.
- Choose **Saved version** to return to a setup you saved before.
- Finish the viewer before applying another version to the live game.
- Keep the controls and complete pairing links private.

Open [Birthday Scam Wheel](https://jhm-hub.github.io/birthday-scam-wheel/) and choose **Prices & settings**. Name the version, edit prices, game names, enabled games, timing or volume, then save. You can save while the viewer is offline.

In the paired private controls, choose **Prices & settings**, select the version, then **Use saved version on live wheel** between viewers. The transparent viewer keeps its existing URL. On the practice page the same button only updates practice.

**Stream setup** shows the permanent OBS link. Existing paired sources keep their link; refresh controls and the existing OBS source once between rounds to load this update. Keep the source at 800 x 900 and disable shutdown/refresh on scene changes.

Existing prices are retained as **My saved settings**. **Export settings** downloads the selected version as a backup. Imported settings remain in the form until saved.
